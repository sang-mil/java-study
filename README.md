## 쓰는 법
- Codex: 저장소 폴더에서 Codex를 열고 `[시험] 지시 확인`처럼 역할 태그 + 명령으로 시작.
- Claude: 상주 채팅에서 "지시 확인" (상주 설정은 `claude/05_세션프롬프트.md`).
- 끝낼 때는 항상 "종료" → 문서 갱신 + 커밋.
