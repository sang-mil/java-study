# 세션 지시서 (운영 → 각 세션)

운영 세션이 여기에 다음 할 일을 적는다. 각 세션(고정 채팅)은 학습자가 **"지시 확인"**이라고 하면
이 문서에서 자기 항목을 읽고, 상태가 `대기`인 지시를 그대로 수행한다.
수행을 시작하면 `진행 중`, 끝나면 `완료`로 바꾸고 결과 한 줄을 적는다.
지시 내용이 이 문서와 00_운영가이드의 규칙과 어긋나면 가이드가 우선이며, 학습자에게 알린다.
